# Altitude Market — Hydrogen Creator Commerce Template

An opinionated Shopify Hydrogen storefront for creator-curated and cross-border commerce.

![Altitude Market social preview](./public/og.png)

This repository is a **runnable storefront template**, not an Agent Skill. Generic e-commerce Skills already cover code generation, theme editing, research, and marketplace operations; this project focuses on the finished customer experience and a reusable technical base.

## Why this template exists

Most commerce starters lead with a generic hero and product grid. Altitude adds a clearer point of view:

- creator-led product edits rather than anonymous recommendations;
- editorial storytelling alongside Shopify-native catalogue, cart, search, accounts, and checkout;
- dedicated content modules for delivery, duties, sizing, currency, returns, and other cross-border expectations;
- a real Hydrogen application that can use Mock.shop data locally or connect to a Shopify store.

The demo brand is outdoor-focused so the interface has concrete, realistic content. Replace it with any category by editing the central configuration and the homepage modules.

## Current stack

- Shopify Hydrogen `2026.4.x`
- React Router `7.16`
- Vite `8`
- TypeScript
- Shopify Oxygen-compatible worker runtime

## Included commerce routes

- Home and curated collection surfaces
- Collections and product details
- Cart and discount handling
- Predictive search
- Customer account, addresses, profile, and orders
- Pages, blog, policies, sitemap, and robots.txt

## Template-specific modules

- Editorial hero and collection story
- Creator edit block
- Cross-border clarity cards
- Branded header and footer
- Central demo-brand configuration in `app/lib/market-config.ts`

The creator and cross-border blocks are presentation modules. Replace demo statements with verified merchant policies before production. Creator attribution, commission tracking, duties calculation, and localization require explicit integrations; the template does not pretend those systems are already configured.

## Run locally

Requirements: Node.js `22` or `24`.

```bash
npm install
cp .env.example .env
npm run dev
```

The unlinked local environment uses Mock.shop sample inventory. No Shopify account is required for the demo. Replace the example session secret before sharing or deploying an environment.

## Connect a Shopify store

```bash
npx shopify hydrogen link
npx shopify hydrogen env pull
```

Review every environment variable and policy statement before deploying. Never commit private Storefront API credentials.

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

## Repository history

The original repository was generated by `shopify[bot]` in July 2023 as a minimal Hydrogen Hello World project. The modernized template replaces the obsolete Remix/Node 16 scaffold while preserving the repository history when applied as an upgrade branch.
